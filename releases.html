Release notes

What changed in each version of WikiMe. The newest is at the top.

Version 1.0.2 26 November 2026Latest

  • Fixes articles saying you were offline with Tor switched on. WikiMe now talks to Tor directly and hands it the site's name, so it works the same on every phone.
  • With Tor on, pages get more time to arrive, and a Tor hiccup is reported as Tor rather than as being offline.

Version 1.0.1 26 November 2026

  • Fixes articles not opening on some phones: the page now loads straight from the app every time.

Version 1.0.0 26 November 2026

  • First release. A private reader for Wikipedia that talks only to Wikipedia and never shows a web address.
  • Explore: featured article, picture of the day, in the news, on this day, most read and did you know.
  • Article reader with a photo header, book-style type, a facts box card, folding sections, note pop-ups, link previews, find in page and a full-screen picture viewer.
  • Five themes, text size, serif or sans, spacing and justify. Data saver and text only.
  • Optional Tor switch, encrypted address lookups and certificate pinning to Wikipedia.
  • Saved articles with pictures for offline reading, reading lists, history with private reading, and highlights with notes, all encrypted on the phone.
  • 44 languages, and any article in every language that has it.
  • Read aloud, Nearby, Look up in WikiMe from other apps, shake for a random article and three home screen widgets.
  • App lock with a PIN or fingerprint, screenshot blocking, hide from recent apps and a tablet layout.

Checking your download

The file for version 1.0.2 is called WikiMe.apk. It is 24.9 MB (24,890,715 bytes). Its SHA-256 checksum is:

0aed43a8c4a97983ac9cbb0f1ec695224dede9437a01562ec64103b3794efe32

On Windows, run certutil -hashfile WikiMe.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
