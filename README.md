# WikiMe

WikiMe is a private reader for Wikipedia on Android. It only ever talks to Wikipedia, never shows a web address, can route everything through Tor, and keeps saved articles, history and highlights encrypted on your phone. No account, no adverts, no tracking.

Website: https://customgpter.github.io/wikime/

Download: https://github.com/CustomGPTer/wikime/releases/latest/download/WikiMe.apk
